# AI Resume Screening System

An AI-based application that screens resumes against a given job description and ranks candidates based on relevance.

## Project Overview
The system helps simplify the resume screening process by evaluating resumes according to the requirements provided in a job description.

## Key Features
- Accepts a job description.
- Screens submitted resumes against the job description.
- Ranks resumes based on their relevance.

## Technologies Used
- Python
- TensorFlow

## Objective
To make the initial resume screening process more efficient through AI-based evaluation.
